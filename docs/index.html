This browser can't talk to USB devices. Use Chrome or Edge on a computer, or Chrome on Android with a USB OTG cable. iPhone and iPad are not supported.

Android: connect the robot with a USB OTG cable, then press Connect and choose "Maker Sumo RP2350". If it isn't listed, close any other app that uses the USB port.

Motors stay off while the configurator is connected. Disconnect, then press START or use the IR module to run.

Motor trim

If the robot drifts, reduce the stronger side. Negative values slow the left motor, positive values slow the right motor. Trims are kept separately for forward and backward driving.

0
0

Range −25 to +25 percent. 0 means both motors get the same power.

RC channels

Choose which servo header carries throttle and which carries steering. Swap this if pushing the stick forward turns the robot instead of driving it.

Fight

How the robot searches, attacks and recovers from the ring edge. Speeds are percent of full power; times are milliseconds.

Defense

Used when the DIP switches are set to 5 (ON OFF ON). The robot waits, moves a little, and repeats until it sees the opponent or runs out of repetitions.

Opening moves

Each DIP position has up to five timed moves the robot performs at the start of a match before it begins searching. Disabled rows are skipped.

Backup
